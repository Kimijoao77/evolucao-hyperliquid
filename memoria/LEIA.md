# Memória das gerações

Um arquivo por geração fechada (`geracao-0001.json`, `geracao-0002.json`, ...), gravado pela própria rotina.

Cada arquivo guarda, de todos os robôs que viveram naquela geração: o DNA, os pais, as medidas (retorno, retorno
no estresse, queda, nota), o estado (em prova, selecionada, confirmada) e, de quem saiu, o motivo.

Nada daqui volta sozinho para a população. A memória serve para estudar o que funcionou em cada época e para
conferir, com os anos, se a evolução está de fato ganhando do sorteio.
